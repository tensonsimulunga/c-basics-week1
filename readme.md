Author: Tenson Simulunga
Student Number: 2025015922
Overview
This project is a console-based Online Banking System written in C. It allows users to create accounts,
log in, perform banking operations, and track transactions. The system demonstrates the use of
structures,
arrays, functions, string handling, and date/time in C programming.
Features
1. Account Management
- Create account
- Secure login system
- Change password
2. Banking Operations
- Deposit funds
- Withdraw funds
- Transfer funds
- Zambian Kwacha (ZMW) currency
3. Transaction History
- Records date & time
- Stores up to 100 transactions per account
4. Account Details
- View name, account number, balance

Technical Concepts Used
- Structures (struct)
- Arrays of structures
- String functions
- Time/date handling
- Input validation
- Menu-driven programming
How to Compile
gcc banking_system.c -o banking
How to Run
./banking
